🃏 TCG Terminal
==============

A mobile inventory tracker for TCG collectors.
Track 5,000+ cards with cost basis priority.


QUICK START — Just double-click index.html!
--------------------------------------------
No install. No server. No terminal needed.
Open index.html in Chrome or Edge and it just works.

📊 Dashboard  — total investment, portfolio chart, recent activity
📋 Inventory  — search, filter by set/rarity/condition/price
◎ Scanner    — live QR & DataMatrix scanning via camera
⬡ Logistics  — CSV import/export, operation history
🖨 Print      — generate DataMatrix labels for NK_P21 printer
🔔 Sound     — Pokémon item-get sound on card recognition
💾 Persistent — data saved to browser, survives refresh


REQUIREMENTS
-------------
• Chrome 83+ or Edge 83+ (for camera scanning)
• Camera access enabled
• No install required — runs entirely in the browser
